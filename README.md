## ⏱️ Complexity Analysis

As the repository develops, algorithms will be documented with their **time and space complexity** where appropriate.

Example:

| Algorithm | Best | Average | Worst |
|---|---:|---:|---:|
| Linear Search | O(1) | O(n) | O(n) |
| Binary Search | O(1) | O(log n) | O(log n) |
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |

> Complexity values describe the algorithmic approach and may vary depending on the specific implementation.

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/DSA.git
```

Navigate into the repository:

```bash
cd DSA
```

Compile any C++ file:

```bash
g++ Arrays/ArraySum.cpp -o ArraySum
```

Run it on Windows:

```bash
.\ArraySum.exe
```

> Executable/build files are not intended to be stored in this repository. Only source code and relevant project files should be committed.
